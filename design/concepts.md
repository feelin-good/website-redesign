# Concepts

Candidates, tested for being specific (a competitor can't reuse it), generative (fills the translation
table) and credible to plant engineers and procurement heads.

| # | Concept | Specific | Generative | Credible | Keep |
|---|---|---|---|---|---|
| 1 | **The drawing set**: the site is a General Arrangement drawing package. Title block, grid references, dimension lines, revision clouds, drawing register | ● | ● | ● | ✔ |
| 2 | **The route**: the site is one material-flow line, mine → crusher → overland conveyor → stockyard → port. Sections are transfer towers TT-1…TT-8 (from their own Vedanta flowsheet) | ● | ● | ◐ | ✔ |
| 3 | **The nameplate**: every machine leaves the works with a riveted rating plate (capacity, boom, year, works no.). Projects become stamped plates; the type is engraved/stencilled | ● | ◐ | ● | ✔ |
| 4 | Commissioning logbook (dated entries, stamps) | ◐ | ◐ | ● | – |
| 5 | Circular stockyard dome (radial layout) | ● | ✕ | ◐ | – gimmicky to navigate |
| 6 | Tonnage counter / TPH gauges | ✕ | ◐ | ● | – becomes a dashboard |
| 7 | Steel mill / heavy industry generic | ✕ | ◐ | ● | – any EPC firm |

## Translation tables

### 1 · The drawing set
| Layer | Dictates |
|---|---|
| Typography | Condensed technical lettering for headings (Barlow Condensed), mono for references (IBM Plex Mono), plain sans for prose |
| Layout | A drawing sheet: outer border with grid refs A–F / 1–8, a title block bottom-right, zones |
| Color | Drafting paper, navy "ink" (logo navy), red for revisions/markup (logo gear red) |
| Imagery | Real photos mounted as numbered "plates" with leader-line callouts and dimensions (boom 41.25 m) |
| Motion | Lines draw like a plotter; dimension lines extend; revision clouds stroke in |
| Components | Cards → drawing-register rows; buttons → stamps; nav → sheet index |
| Voice | Terse, numbered: "DWG LP-014 · Bucket wheel reclaimer · 3000 TPH · Rev C" |

### 2 · The route
| Layer | Dictates |
|---|---|
| Typography | Wide grotesk for station names; mono chainage (km 0+000) |
| Layout | A vertical flowsheet line down the page; sections hang off transfer towers |
| Color | Logo navy line on white, red material flowing, yellow machine paint from photos |
| Imagery | Photos at the stations where that machine sits in the flow |
| Motion | Material moves along the line as you scroll; chainage counter ticks |
| Components | Nav = route map; cards = stations; CTA = "Request a route survey" |
| Voice | "TT-3 · Stockyard · stacking 6800 TPH at Mundra" |

### 3 · The nameplate
| Layer | Dictates |
|---|---|
| Typography | Stencil/engraved condensed caps for plates; sans for prose |
| Layout | Heavy photographic bands; plates bolted onto photos |
| Color | Machine paint (yellow/blue) from the photos, brushed steel plates, navy |
| Imagery | Full-bleed photos of machines with their plates |
| Motion | Plates "rivet" in |
| Components | Projects = rating plates; stats = plate fields |
| Voice | "WORKS NO. 465.1691 · STACKER · 1100/1210 TPH · TOROR CEMENT · UGANDA" |
